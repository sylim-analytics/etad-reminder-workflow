# ⏱️ Timesheet Reminder Workflow (AI-Assisted)

**Replaced one group email with personalized, human-reviewed reminders, built with a Copilot agent and Copilot Cowork.**

### 👉 [Try the live demo](https://sylim-analytics.github.io/etad-reminder-workflow/)
> Interactive mockup with fictional data (NovaWorks). No sign-in needed.

## The Problem
Each month, everyone under the required hours got the same group email. People didn't know exactly what they were missing, and contractors received duplicate reminders.

## The Solution
| Step | What it does |
|---|---|
| **Read** | AI reads the monthly missing-hours report |
| **Verify** | Checks each person against the directory and applies standing exceptions |
| **Route** | Employees: personal reminder showing hours entered out of the target hour, supervisor copied. Contractors: summary goes to their supervisor only |
| **Review** | Every draft is approved by a person before anything is sent |

**Key idea:** AI prepares, a human decides.

## How It Evolved
Observed how admins in two directorates ran reminders → built a Copilot agent → moved it to Cowork → redesigned contractor handling with an engineering-services manager and a peer admin.

## Impact
- Every reminder shows **exact hours**, so people know what to fix
- **Removed duplicate emails** to contractors
- **One documented process** across two directorates
